Kas Kecil untuk CasaOS dan Linux
Versi: 1.5.1
Tanggal: 2026-08-12
Arsitektur: amd64
Port default: 8090
Database: SQLite WAL
Repository publik: https://github.com/anggapraditya100111-a11y/kas-kecil-linux

Fitur utama:
- Hak akses granular per pengguna
- SPV tanpa akses input transaksi secara default
- Dashboard sendiri, seluruh pengguna, dan filter per pengguna
- Approval melalui tautan publik dengan PIN SPV 8 digit
- Mutasi kas per pengguna dengan saldo berjalan dan export Excel/PDF
- Daftar akun dan limit yang dapat dilihat staff
- Transfer kas antar-staff dengan approval SPV
- Koreksi transaksi melalui reversal tanpa menghapus audit trail
- Uang Muka Operasional (UMO) dan pertanggungjawaban multi-akun
- Bukti privat, audit log, laporan, dan backup otomatis
- Blokir kegagalan login/PIN dipersingkat menjadi maksimal 1 menit
- Generator nomor dokumen diselaraskan otomatis dengan data lama
- Input nominal Rupiah dengan pemisah ribuan otomatis
- Logo perusahaan dan warna tema dapat diatur oleh Super User
- Tampilan adaptif mobile/desktop dengan dark mode
- Bukti transaksi dapat langsung diambil dari kamera perangkat
- Tautan approval hanya-baca dapat disalin dari menu terkait
- PDF tanda terima pencairan UMO
- Cache frontend divalidasi ulang agar UI domain selalu memakai aset seversi
- Dukungan installer Linux umum dan distribusi repository public
- Rekap total dana per akun dengan filter tanggal dan export Excel/PDF
- Pemeliharaan data khusus Super User dengan backup manual dan riwayat backup
- Reset data transaksi aman dengan backup historis otomatis sebelum penghapusan
- Sidebar accordion desktop/mobile dan informasi versi aplikasi
- Filter periode Dashboard dengan default bulan berjalan
- Export/restore data lengkap terenkripsi untuk pemindahan server
- Perbandingan dana per akun antarbulan dengan cakupan hak akses pengguna
- Underlying document opsional/wajib per akun untuk dasar pengeluaran
- Pagu kas bulanan per akun, periode terkunci, dan proses End of Month
